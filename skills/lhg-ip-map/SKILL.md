# lhg-ip-map：知产四象限判断框架

## 1. 何时使用

- 用户说"我有个产品/品牌，不知道该保护什么" → 跑判断问卷，输出四象限矩阵。
- 用户问"商标和著作权有什么区别""配方是申请专利还是当商业秘密" → 给对比表。
- 用户只想保护一个点（如只注册商标）→ 检查是否漏掉其他象限。

不适用：涉外申请（马德里/ PCT 等，提示咨询专业代理机构）；具体侵权诉讼策略（提示咨询律师）。

## 2. 输入与输出

**输入**：产品/品牌一句话描述 + 4 个判断问题答案（见 3.2）。
**输出**：
- 四象限矩阵：每项资产 → 保护类型 → 为什么是这个类型 → 优先级（P0 先做 / P1 后做）
- 每类权利的"保护什么/不保护什么"一句话
- 末尾附声明块。

## 3. 分步方法论

### 3.1 四象限总览（公开常识整理）

| 象限 | 保护对象 | 一句话 | 权利来源 | 有效期（公开常识，以官方为准） |
|---|---|---|---|---|
| 商标 | 品牌名、Logo、 slogan | 防止别人用近似标识搭便车 | 申请 + 核准注册 | 10 年，可续展 |
| 著作权 | 代码、文章、设计稿、视频 | 保护"表达"不保护"思想" | 创作完成自动产生，登记是证据补强 | 自然人作品为作者终生+50年（以法律为准） |
| 专利 | 技术方案、产品结构、外观设计 | 保护技术/设计的独占实施权 | 申请 + 审查授权 | 发明 20 年，实用新型/外观 10 年（以法律为准） |
| 商业秘密 | 配方、工艺、客户名单、算法细节 | 不公开、靠保密措施维持 | 不申请，靠保密管理 | 保密多久有效多久，泄密即失效 |

### 3.2 判断问卷（4 问）

1. 要保护的是**名字/标识**（让人认出你）还是**内容/技术**（别人抄不走的东西）？→ 前者走商标，后者继续问。
2. 内容是**表达性**的（代码/文案/设计）还是**技术性**的（方法/结构/配方）？→ 表达走著作权，技术继续问。
3. 技术方案是否**必须公开**才能商业化（如产品结构一眼能看出来）？→ 是则走专利；否则继续问。
4. 能否通过**保密措施**长期控制（如配方不公开、签保密协议）？→ 是则商业秘密 + 配套保密管理；否（容易被反向工程）则走专利。

**组合是常态**：一个 App 通常 = 商标（名字+图标）+ 著作权（代码+UI）+ 专利（核心算法/交互，视情况）+ 商业秘密（运营数据/策略）。矩阵要逐项列出，不要只给一个。

### 3.3 优先级排序规则

- **P0（上线前必须做）**：商标检索与申请（品牌一旦做起来被抢注，改名成本极高）；核心代码/设计稿的证据留存。
- **P1（业务跑起来后）**：著作权登记（证据补强）、防御类商标（近似名、跨类）。
- **P2（有技术壁垒时）**：专利申请（周期长、费用高，评估投入产出后再定，提示咨询专利代理师）。
- **持续项**：商业秘密的保密管理（协议+权限+审计，永远在线）。

### 3.4 常见误判纠正

- ❌ "我注册了公司，品牌就受保护了" → 公司字号 ≠ 商标权，字号只在登记辖区内有一定保护，商标是全国/全类（注册类）保护。
- ❌ "我买了域名，商标就是我的了" → 域名 ≠ 商标，互不隶属。
- ❌ "著作权登记了，思想就被保护了" → 只保护表达，别人用不同代码实现相同功能不侵权。
- ❌ "配方申请专利最保险" → 专利要公开技术细节，配方类（如可乐配方）公开了就没壁垒了，保密可能是更好选择；但保密一旦泄密则无救济，各有利弊，请咨询专业人士。
- ❌ "外观好看就去申请外观专利" → 先确认是否满足新颖性等授权条件，提示咨询专利代理师。

```
知产四象限矩阵（产品：山野咖啡）
| 资产 | 类型 | 优先级 | 说明 |

| 包装设计稿 | 著作权 | P0 | 创作过程留痕+登记补强 |

⚠️ 声明：本矩阵非律师意见、仅供参考；审查标准以官方最新公告为准。
```

## 4. 反模式（不要这么做）

- ❌ 用户只问商标，就只给商标——必须过一遍四象限，防止漏保护。
- ❌ 说"这个肯定能注册/授权"——审查结果由官方定，不预测。
- ❌ 把"商业秘密"说成"申请商业秘密"——商业秘密不申请，靠保密管理。
- ❌ 推荐具体的代理机构并承诺效果——只给"选择代理机构的考察维度"。
- ❌ 虚构各国有效期/费用数字——一律写"以官方最新公告为准"。

## 附：常见问题快答

**Q1：个人能申请商标吗？**
A：可以。自然人凭身份证（个体户加营业执照）就能申请，不一定非要公司；具体材料以官方最新要求为准。

**Q2：商标和 Logo 版权要同时做吗？**
A：建议都做：Logo 图形可以同时注册商标 + 做著作权登记，双保险；图形被驳回时著作权登记还能作为在先权利证据。

**Q3：R 和 TM 有什么区别？**
A：R 是注册成功才能标，TM 是"在当商标用"的宣示，法律效力不同；没注册下来就标 R 是违法行为。

**Q4：发现别人用了我的品牌名怎么办？**
A：先固定证据（时间戳/公证思路），再看对方是否在你注册的类别上使用，然后走平台投诉或发函路径；具体策略咨询专业人士。

**Q5：开源代码还有著作权吗？**
A：有。开源不等于放弃著作权，开源协议（如 MIT/GPL）是"附条件的许可"，违反许可条件仍可维权。

**Q6：员工上班时间写的代码归谁？**
A：一般看合同：职务作品默认规则 + 合同约定，合同优先；入职时没写清是最高发的纠纷，签劳动合同时一并约定。

**Q7：商业秘密要签什么协议？**
A：保密协议（在职）+ 竞业限制协议（离职，核心人员），再加内部权限管理与离职交接审计；光签协议不做管理等于没做。

**Q8：被抢注了商标怎么办？**
A：看阶段：公告期内可异议，注册后可无效宣告/撤销连续三年不使用；每条路径都有时限，尽快咨询专业人士，不要拖。

## 附二：术语速查表

| 术语 | 一句话解释 |
|---|---|
| 尼斯分类 | 商标注册用的 45 大类商品/服务分类 |
| 在先权利 | 比你早申请/早产生的权利，审查时优先保护它 |
| 显著性 | 商标能让人认出"这是谁家"的能力，越独特越强 |
| 初审公告 | 审查通过后 3 个月的公示期，谁都可提异议 |
| 异议 | 公告期内第三方说"这个不该注册"的程序 |
| 续展 | 10 年到期前申请延长 10 年，可无限续 |
| 撤三 | 连续三年不使用，别人可申请撤销你的商标 |
| R / TM | R=已注册，TM=当商标用（未必已注册） |
| 职务作品 | 为完成单位任务创作的作品，权属看合同约定 |
| 委托作品 | 花钱请人创作的作品，权属没写清就容易扯皮 |

# lhg-ip-defense：侵权取证与维权路径清单

## 1. 何时使用

- 用户说"有人抄我的产品/用了我的品牌名/搬运我的内容" → 跑三步维权流程。
- 用户问"要保留哪些证据" → 给证据清单（每条证据标注"证明什么"）。
- 用户问"去哪里投诉" → 给平台投诉通道查找方法 + 投诉材料清单。

不适用：要求判断"这个官司能不能赢"→ 不给结论，请咨询律师；要求伪造/加工证据 → 直接拒绝。

## 2. 输入与输出

**输入**：侵权线索描述（谁/在哪/抄了什么/什么时候发现的）+ 用户手里的权利证明（商标注册证/著作权登记证书/专利证书/创作底稿）。
**输出**：
- 证据固定清单（已有什么/还缺什么）
- 平台投诉材料包清单
- 三路径对比（协商/行政投诉/司法）+ 选择考虑因素
- 全程时间线记录表模板
- 末尾附声明块。

## 3. 分步方法论

### 3.1 第一步：固定证据（发现侵权 48 小时内做）

证据灭失是最常见的维权失败原因。按"证明什么"逐项固定：

| 证据 | 证明什么 | 固定方法 |
|---|---|---|
| 侵权页面/商品链接 | 侵权事实存在 | 可信时间戳、第三方存证平台、必要时公证 |
| 侵权方主体信息 | 告谁 | 店铺资质页、工商信息截图（同上固定） |
| 销量/销售额 | 损失规模 | 商品页销量、评价数截图（固定） |
| 自己的权利证明 | 我有权利 | 商标注册证/登记证书/创作底稿+时间线 |
| 首次发表/使用证据 | 我在先 | 发布时间戳、首发平台记录、合同发票 |

**方法说明**：可信时间戳（证明"这个时间这个内容存在"）、第三方电子存证（平台出证）、公证（公信力最高、费用也最高）。三者按"成本-效力"排序，金额大的纠纷直接上公证，小的先用时间戳+存证。

**反模式**：只截图不固定（截图可 PS，证明力弱）；找对方"理论"打草惊蛇（对方下架后证据就没了）。

### 3.2 第二步：平台投诉（最快、成本最低）

各大电商/内容平台都有知识产权保护通道（名称各平台不同，一般叫"知识产权保护""侵权投诉"）：

1. 到该平台官网底部或帮助中心搜"知识产权"，找到投诉入口（**以平台最新公布的入口为准**，本 skill 不写死链接）。
2. 准备投诉材料包：权利证明（注册证/登记证书）+ 侵权链接清单 + 对比说明（哪里抄了）+ 联系方式。
3. 提交后记录投诉单号，跟进处理进度；一次没通过看驳回理由补材料再提。

**预期管理**：平台投诉处理的是"通知-删除"层面的事，复杂争议（到底算不算近似）平台可能不判，转线下路径。不承诺处理结果与时限。

### 3.3 第三步：三路径选择（协商 / 行政 / 司法）

| 路径 | 适合 | 成本 | 注意 |
|---|---|---|---|
| 协商/发函 | 对方是小商家、想快速下架 | 低 | 函件只陈述事实与诉求，不威胁恐吓 |
| 行政投诉 | 假冒商标等明显的违法 | 中 | 向市场监管部门/版权局投诉，以官方认定为准 |
| 司法诉讼 | 金额大、对方硬刚、要赔偿 | 高 | 必须请律师；诉讼时效注意（发现侵权后别拖） |

选择只给考虑因素（金额大小、对方态度、证据强度、时间成本），**不给"选这个准赢"的结论**。

### 3.4 全程时间线记录表

```
日期 | 动作 | 证据编号 | 备注
10-11 | 发现侵权链接3条 | E001-E003 | 已做时间戳固定
10-12 | 平台投诉提交 | C001 | 单号XXX，待处理
...
```

维权是持久战，时间线不清等于白干。

### 3.5 日常证据留存（没被侵权时就要做）

- 创作过程留痕：设计稿保留版本迭代（v1/v2/终稿）+ 时间。
- 品牌使用留痕：带日期的广告投放、销售合同、发票（防"撤三"、被异议时用）。
- 商业秘密：保密协议签署记录、权限分级记录、离职交接记录。
- 定期备份：云端+本地双备份，防止"证据在离职员工电脑里"。

## 4. 反模式（不要这么做）

- ❌ 教用户 P 图"补证据"、找水军刷差评报复——直接拒绝，这是违法的。
- ❌ 说"投诉了平台一定下架"——不承诺结果。
- ❌ 让用户先去跟对方对骂再固定证据——先固定，后交涉。
- ❌ 把律师函写成恐吓信——函件只陈述事实与诉求。
- ❌ 建议"买凶删帖/黑客攻击对方店铺"——违法，直接拒绝。

## 5. 自检与反馈

**质检门**：
- [ ] 证据清单是否每条标注"证明什么"？
- [ ] 是否强调"先固定后交涉"？
- [ ] 平台投诉是否写"以平台最新入口为准"而不写死链接？
- [ ] 三路径是否只给考虑因素、不给胜算结论？
- [ ] 是否出现承诺性表述？末尾是否有声明块？

**标准冒烟用例**：输入"有人在电商平台用近似名卖同款，我有商标注册证"→ 应输出证据清单 + 投诉材料包 + 三路径对比，末尾带声明。

**一键提 issue**：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-ip/issues，正文写清"复现步骤 → 实际表现 → 期望表现"。

## 附：常见问题快答

**Q1：没注册商标能维权吗？**
A：难。有一定影响的未注册驰名商标有保护，但举证门槛极高；普通小品牌没注册基本维权无门，先注册再谈维权。

**Q2：对方把我的图改了改还算侵权吗？**
A：看"实质性相似"，不是"一模一样才算"；但认定的专业性很强，把对比材料整理好后咨询专业人士。

**Q3：投诉要花钱吗？**
A：平台投诉本身一般不收费；公证、诉讼要花钱。先走免费的平台投诉，不行再升级。

**Q4：发律师函必须请律师吗？**
A：律师函要律师发才叫律师函；自己发的叫"维权函"，效力不同。金额大的建议请律师。

**Q5：对方在国外平台侵权怎么办？**
A：走该平台的国际投诉通道（如适用），或在其所在国维权；跨境维权成本高，先评估金额再定，请咨询专业人士。

**Q6：证据固定越贵越好吗？**
A：不是。按纠纷金额匹配：几千块的纠纷做公证可能倒挂；先时间戳+存证，不够再升级。

**Q7：可以要求对方赔偿吗？**
A：可以主张，但赔偿数额看证据（实际损失/侵权获利/法定赔偿），别张口就喊天价，准备好计算依据。

**Q8：维权要多久？**
A：平台投诉几天到几周；行政数月；诉讼数月到一年以上。问"多久能赢"的一律回答：看路径和证据，具体咨询律师。

## 附二：术语速查表

| 术语 | 一句话解释 |
|---|---|
| 可信时间戳 | 证明"这个时间这个文件存在"的电子凭证 |
| 电子存证 | 第三方平台对电子证据的存管，出证快 |
| 公证 | 公证处对证据的证明，公信力最高、费用也最高 |
| 通知-删除 | 平台接到合格投诉后下架侵权内容的机制 |
| 在先使用 | 没注册但用得早，特定条件下可抗辩 |
| 实质性相似 | 不必一模一样，核心表达相同即可能侵权 |
| 法定赔偿 | 损失算不清时法院按法律幅度判的赔偿 |
| 诉前禁令 | 起诉前请求法院先让对方停下来的程序 |

# lhg-ip-tm：商标注册实务

## 1. 何时使用

- 用户要给品牌名/Logo 注册商标 → 跑显著性初筛 → 类别选择 → 申请流程。
- 用户问"选哪几类" → 用三层选择法。
- 用户收到驳回通知 → 跑驳回原因分析 + 复审决策框架（不承诺成功率）。

不适用：马德里国际注册（提示咨询专业代理机构）；商标转让/许可合同条款（提示咨询律师）。

## 2. 输入与输出

**输入**：商标名称/图样 + 所属行业 + 核心商品/服务描述。
**输出**：
- 显著性初筛结论（通过/风险提示/硬伤）
- 类别建议（核心类 + 防御类 + 关联类，注明尼斯分类号）
- 申请流程图 + 材料清单（checklist.json）+ 时限节点
- 驳回预案（常见原因 + 复审决策框架）
- 末尾附声明块。

## 3. 分步方法论

### 3.1 显著性初筛（申请前必做）

商标要有"显著特征"，便于识别。初筛三问：
1. 是否**通用名称**？（如"咖啡"做咖啡商标）→ 硬伤，换名。
2. 是否**直接描述**商品特点？（如"好喝"做饮料）→ 显著性弱，建议加图形/臆造词组合。
3. 是否含**禁用情形**？（国名国徽、有害道德风尚、夸大宣传如"第一""顶级"）→ 硬伤，换名。

结论只分三档：**通过**（可进入检索）、**风险提示**（显著性弱，建议调整）、**硬伤**（建议换名）。不写"一定能过"。

### 3.2 尼斯分类三层选择法

商标按尼斯分类 45 个大类注册，**注册哪类保护哪类**。

- **核心类**：产品/服务本身所在的类。如咖啡：第 30 类（咖啡、茶）；App：第 9 类（可下载软件）；服装：第 25 类。**必须选**。
- **关联类**：业务上下游。如咖啡品牌加第 43 类（餐饮服务）、第 21 类（咖啡具）；App 加第 42 类（软件开发服务）、第 35 类（广告销售）。
- **防御类**：容易被傍名牌的类、未来可能扩张的类。按预算取舍，预算有限先保核心类。

**新手最常见的坑**：只注册第 35 类（广告、商业经营）。第 35 类保护的是"替他人做广告/销售"服务，**保护不了你自己的产品**。卖咖啡只注 35 类，别人照样可以在 30 类上用近似名卖咖啡。

输出格式："核心类：第 30 类（咖啡、茶、可可）——理由：产品本身；关联类：第 43 类……；防御类：……"

> 类似商品/服务的具体划分以官方《类似商品和服务区分表》为准，拿不准的类别提示咨询专业人士。

### 3.3 申请流程（以官方最新公告为准）

1. **准备材料**：申请书、申请人身份证明、商标图样、商品/服务清单（见 checklist.json）。
2. **提交申请**：商标局官网网上申请或窗口/代理提交，拿申请号。
3. **形式审查**：材料齐不齐（约 1 个月量级，以官方为准）。
4. **实质审查**：显著性 + 近似检索（约数个月，以官方为准）。
5. **初审公告**：3 个月，任何人可异议。
6. **核准注册**：公告无异议下发注册证，**10 年有效，到期前 12 个月内可续展**。

每个节点标注"以官方最新公告为准"，不写"包 X 个月下证"。

### 3.4 常见驳回原因（公开常识）

| 驳回原因 | 含义 | 应对方向 |
|---|---|---|
| 与在先商标近似 | 有人已注册了近似的 | 复审争辩差异 / 换名重报 / 买标 |
| 缺乏显著性 | 太通用/太描述性 | 加图形组合 / 换臆造词 |
| 不良影响 | 违反禁用条款 | 换名，别硬刚 |
| 商品描述不规范 | 写的商品不在区分表里 | 按区分表规范表述重报 |

### 3.5 驳回复审决策框架（不承诺成功率）

收到驳回通知后三选一：
1. **复审**：自认有理（如近似判断有争议、显著性可通过使用获得）→ 15 日内提复审（时限以通知书为准），准备理由书+证据。
2. **修改重报**：名字本身硬伤 → 换名/加图形后重新申请，成本可能低于复审。
3. **放弃**：品牌可替代性强 → 换赛道名。

决策只给考虑因素（品牌投入沉没成本、复审周期、成功率不确定性），**不给"复审一定能赢"的结论**，提示咨询专业人士。

### 3.6 时限节点提醒卡

- 初审公告 3 个月（异议期）
- 注册 10 年有效，**到期前 12 个月内续展**（宽展期以官方为准）
- 驳回复审：收到通知后法定期限内提出（以通知书载明为准）
- 连续三年不使用可被撤销 → 保留使用证据（发票/合同/广告）

## 4. 反模式（不要这么做）

- ❌ 说"这个名字肯定能注册"——审查是官方的事，不预测。
- ❌ 只给第 35 类——必须讲清三层选择法。
- ❌ 写"3 个月包下证/费用 XXX 包过"——时限费用以官方为准。
- ❌ 替用户下"复审吧，稳赢"的结论——只给决策框架。
- ❌ 推荐具体代理机构并承诺效果——只给考察维度（看执业资质、看收费透明度、看是否承诺包过——承诺包过的不靠谱）。

## 5. 自检与反馈

**质检门**：
- [ ] 显著性初筛三问是否走完？结论是否为三档之一？
- [ ] 类别建议是否分核心/关联/防御三层？是否提醒"只注 35 类"的坑？
- [ ] 流程每个节点是否标注"以官方最新公告为准"？
- [ ] 材料清单是否逐项可打勾？时限提醒卡是否包含续展？
- [ ] 是否出现承诺性表述？末尾是否有声明块？

**标准冒烟用例**：输入"'山野' 咖啡"→ 应输出初筛结论 + 三层类别（含 30/43/35 等）+ 流程 + 时限卡，末尾带声明。

## 附：常见问题快答

**Q1：个人和公司申请有区别吗？**
A：权利归属不同：公司申请归公司，离职带不走；个人申请归个人。创业团队建议以公司名义申请，避免创始人变动扯皮。

**Q2：图形和文字分开申请还是一起？**
A：建议分开。组合申请中任一部分出问题整体被驳；分开申请贵一点但更稳，预算有限先保文字。

**Q3：商标可以加急吗？**
A：官方没有"加急通道"，凡是承诺加急包过的都是骗子，见一个拉黑一个。

**Q4：拿到受理通知书就能用 R 吗？**
A：不能。只有注册成功才能标 R，受理阶段标 TM。

**Q5：类别选多了是不是浪费钱？**
A：按类收费，选多了确实贵；但核心类+关键关联类不能省，防御类按预算来。省小钱丢大权是最亏的。

**Q6：商标名和公司字号必须一致吗？**
A：不用。字号是登记名，商标是品牌名；但两者一致时维权举证更顺，条件允许建议统一。

**Q7：被异议了怎么办？**
A：异议是公告期的正常程序，收到异议答辩通知后在法定期限内答辩，准备使用证据与知名度证据；答辩策略咨询专业人士。

**Q8：续展忘了会怎样？**
A：有宽展期（以官方为准），宽展期再错过商标就失效了，别人可申请；把续展日期写进日历，提前一年准备。

## 附二：术语速查表

| 术语 | 一句话解释 |
|---|---|
| 区分表 | 《类似商品和服务区分表》，写商品项目时的官方词典 |
| 驳回复审 | 不服驳回，15 日内（以通知书为准）请求重新审查 |
| 近似商标 | 看着像、读着像、含义像，容易让消费者混淆的 |
| 臆造词 | 自己编的词（如"海底捞"），显著性最强 |
| 描述性词汇 | 直接说产品特点的词，显著性弱 |
| 防御商标 | 主品牌外注册的近似/跨类商标，防傍名牌 |
| 联合商标 | 同一主体在近似商品上注册的近似商标 |
| 宽展期 | 续展到期后的一段补救期（以官方为准），别拖到这步 |
